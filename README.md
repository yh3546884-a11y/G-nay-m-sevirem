## GitHub Pages-ə yerləşdirmək

1. Bu qovluğu GitHub-a yüklə (yeni repository yarat)
2. **Settings → Pages → Source**: `main` branch / root seç
3. Bir neçə dəqiqə sonra sayt aktiv olacaq:
   `https://USERNAME.github.io/REPO-ADI`
